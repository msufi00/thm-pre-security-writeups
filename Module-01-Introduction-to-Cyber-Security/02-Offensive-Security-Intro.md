# 02 - Offensive Security Intro

## Room / Topic
- Offensive Security Intro

## Objective
- Mengenal pasti apa itu offensive security.
- Memahami bagaimana penyerang memikirkan cara menyerang sistem untuk mencari kelemahan.

## Key Concepts
- Ethical hacking
- Reconnaissance
- Vulnerability assessment
- Exploitation
- Penetration testing

## Questions & Answers

### Question 1
**Question:** Apakah maksud offensive security?

**Answer:** Offensive security ialah pendekatan yang menilai keselamatan sistem dengan cara menyimulasikan serangan untuk mencari kelemahan sebelum pihak tidak dibenarkan menemui dan mengeksploitasinya.

### Question 2
**Question:** Mengapa offensive security berguna?

**Answer:** Ia membantu organisasi mengenal pasti kelemahan sistem, memahami potensi risiko, dan memperbaiki keselamatan sebelum berlaku serangan sebenar.

### Question 3
**Question:** Adakah offensive security sama dengan aktiviti haram?

**Answer:** Tidak. Offensive security yang betul dijalankan secara beretika dan dibenarkan, seperti pentesting atau red teaming, berbeza dengan aktiviti penggodaman tanpa kebenaran.

## Notes
- Offensive security melibatkan pemikiran seperti penyerang, tetapi dalam konteks yang sah.
- Ia penting untuk menilai kelemahan sebenar sebelum sistem digunakan secara besar-besaran.
- Ethical hacking membantu memperkuat sistem dan mengurangkan risiko sebenar.

## Reflection
- Saya belajar bahawa offensive security bukan sekadar "menggodam", tetapi satu langkah profesional untuk menilai dan memperbaiki keselamatan.
- Saya dapat lihat hubungan rapat antara defensive dan offensive security.
- Kesimpulannya, organisasi perlu mempunyai kedua-dua aspek ini untuk menilai kekuatan keselamatan mereka secara menyeluruh.
